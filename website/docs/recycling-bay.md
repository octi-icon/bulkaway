# Space Reclaimed: Recycling Bay

Optional, separate sorting process available from the start screen and hauling results. Twelve materials arrive in three shuffled batches. Players choose paper, plastic, metal, glass, or set aside using labeled buttons or keys 1–5 while focus is inside the game. Correct placement unlocks Next; incorrect choices keep the item and give an explanation. No timer, lost lives, dragging requirement, global keyboard listener, or additional rendering loop.

First-try placements award 100 points plus a streak bonus capped at 100. Corrected placements award 50; already sorted items cannot award again. Sorting points never alter hauling personal bests. Players may return to an earned reward at any point. Completion also offers the existing SPACE5 reward.

Pixel SVG silhouettes, conveyor shading and finite stepped transitions reuse the existing palette and sound opt-in. Motion respects both reduced-motion and the site's paused-motion preference. React state and pure domain functions add no dependencies.

Material model references: [EPA common recyclables](https://www.epa.gov/recycle/how-do-i-recycle-common-recyclables), [EPA recycling questions](https://www.epa.gov/recycle/frequent-questions-recycling), [EPA lithium-ion batteries](https://www.epa.gov/recycle/used-lithium-ion-batteries). Empty/rinsed containers and clean/dry paper are the examples; lithium batteries and film bags use separate handling. Material streams represent the game sorting facility, not a promise of Bulk Away acceptance or every local curbside program.
